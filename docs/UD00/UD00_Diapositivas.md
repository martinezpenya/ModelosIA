!!! note "Cómo se generan"
    Las diapositivas se escriben en Markdown con [Marp](https://marp.app/) y se generan a PDF y
    HTML con `./generar-diapositivas.sh UD00`. El guion es
    `docs/UD00/Presentacion/UD00_1_ES.md`: si hay que corregir algo, se corrige ahí y se regenera,
    nunca se edita el PDF.
