## `T01` · Control de versiones con GitHub

Crear la cuenta y el repositorio de GitHub que usarás más adelante en el proyecto de Robocode
de la UD02. Saber moverse en un repositorio es parte de las herramientas del oficio.

**Se entrega** en Aules un único fichero **PDF** con:

- la captura de tu perfil de GitHub;
- la captura del *pull request* con sus cuatro campos explicados;
- la captura del estado final del *pull request*.

## `T02` · Documentar con Markdown

Aprender Markdown lo bastante como para documentar cualquier proyecto. La memoria del bot de
Robocode de la UD02 se escribe más rápido dominándolo, y es el lenguaje en el que están
escritos estos apuntes.

**Se entrega** en Aules un único fichero **`.zip`** con:

- el documento en Markdown (`.md`);
- el PDF exportado a partir de ese `.md`.

## `T03` · Verificación del entorno y primer contenedor

Instalar Docker, verificar que funciona y levantar un primer contenedor. Es el requisito de
todo lo demás: sin entorno no se pueden hacer las prácticas de la UD02.

**Se entrega** en Aules un único fichero **PDF** con:

- la memoria con las capturas y las justificaciones de las seis fases.

## `T04` · Contenedor de prácticas de IA

Construir el contenedor con el que se trabaja el resto del módulo, con Python y las librerías
de IA dentro. Al terminar tienes el entorno del curso levantado.

**Se entrega** en Aules un único fichero **PDF** con:

- la memoria con las evidencias pedidas en el apartado «Entrega» (capturas de las fases 5 y 7, salida de `docker compose ps` y la respuesta razonada).
